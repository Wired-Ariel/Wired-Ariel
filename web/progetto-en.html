gen3-poke-multiplayer

Watch your friends walk around the Pokémon Emerald overworld, on original Game Boy Advance hardware and cartridges, over the internet. This page explains how it really works.

The idea

Pokémon Emerald has no feature to show another player walking on your map: the link cable is only used for trades and battles in dedicated rooms. This project adds that feature without modifying either the cartridge or the save file: a small program is loaded into the console's volatile memory at every power-on, reads your character's position, sends it to your friends over the internet, and draws their characters in your game using the same functions the game uses to draw its own NPCs. Nothing is left when you switch off: the GBA's working memory is volatile.

Currently supported: the Italian release of Pokémon Emerald.

The chain, from one GBA to another

GBA ↔ link cable ↔ adapter (Raspberry Pi Pico with Celio firmware) ↔ USB ↔ browser or PC ↔ internet (WebSocket/UDP) ↔ forwarding server (relay) ↔ … and from there, in reverse, to your friend's GBA

Each link does one thing only:

  • The link cable is the standard 5-pin GBA cable. The adapter speaks to the GBA the serial protocol the console has always used for multiplayer (16-bit Multi-Player mode, the same as the Cable Club).
  • The adapter is a Raspberry Pi Pico (RP2040) running the Celio project firmware, extended for this project with a passthrough mode: it moves data between cable and USB without interpreting it.
  • The browser (Chrome or Edge, via WebUSB) or a program on the PC drives the adapter, wraps game events into packets and sends them to the server.
  • The relay is a small server that forwards packets between the players in the same «room». It doesn't understand the content: it just delivers it.

How the program gets into the GBA (resident multiboot)

The GBA has a built-in feature called multiboot: if you switch it on without a cartridge but with the link cable plugged in, it accepts a small program over the cable and runs it from RAM. This is the whole sequence to play:

  • switch the GBA on with the cartridge slot empty and the cable plugged in;
  • the PC (or the browser) loads our program over the cable (~15 seconds, red screen);
  • insert the cartridge while the console is on (green screen) and the game boots normally, with our program already resident in a corner of memory the game doesn't use;
  • from then on you just play: nothing to do inside the game, ever.

The resident program hooks into the game by rewriting a pointer in RAM (the interrupt vector, which the game itself keeps in writable memory) and from there it runs once per frame, alongside the game, without touching a single instruction of the cartridge — which is mask ROM, physically unwritable.

How your friends are drawn

The program reimplements nothing: thanks to the game's decompilations (the pret project) we know the address of every original function, and the remote character is created and moved by calling the same functions the game uses for its NPCs. That's why your friend walks with the game's real animation. We send actions («I took a step north»), not a stream of coordinates: ~12 bytes per update are enough, and the system copes well with internet latency.

What you need to play

  • a GBA (or GBA SP) and an original Italian Pokémon Emerald cartridge;
  • the USB-to-link-cable adapter (Raspberry Pi Pico with the provided firmware) and an original or compatible GBA link cable;
  • Chrome or Edge on a PC (for the browser route), with the WinUSB driver on Windows (installed once with Zadig);
  • instead of a real GBA: the mGBA emulator with the provided script — real GBAs and emulators play together, in the same room.

What the project doesn't do

Online trades and battles go through the game's Cable Club and work both from the PC panel and from the browser (tested on real hardware on 27 August 2026). The project doesn't modify the ROM (impossible: it's mask ROM) and doesn't touch the save file. It doesn't distribute the game or any part of it: you need your own cartridge.
